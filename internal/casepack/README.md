## 重放情形

- 气氛延迟：阀在 480 s 切换，气氛有效区间从 540 s 开始，反应证据从 600 s 开始。
- 天平基线漂移：线性漂移先为 `0.002 mg/min + 0.001 mg`，后续重估。
- 重叠峰：窄窗口与宽窗口候选同时保留，阶段损失不强制合计 100%。
- 非单调噪声：780 s 的正质量步和正 DTG 保留，不做平滑。
- 采样缺口：540–660 s 超过 90 s 阈值；质量、DTG 和阶段均不跨缺口插值。
- 初重修订：`10.50 mg` 修订为 `10.48 mg`，只使百分比依赖过期。
- 导入半失败：重复不可变源 ID 与未知通用表格层同时提交，整批回滚但失败事件、片段和诊断保留。
