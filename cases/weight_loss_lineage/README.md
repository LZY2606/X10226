# 失重谱系：TGA 阶段分解、气氛切换与残留物证据链（离线案例包）

本目录是**领域专用**离线案例，不依赖公网，也不是通用表格。所有材料可直接复制进
系统的导入框。固定采样间隔与固定时钟（`2026-01-01T00:00:00Z`）保证重放逐字节一致。

## 基线版本（一次完整分层导入）
- `baseline/samples.csv` —— 原始采样点（炉时间 / 温度 / 质量，逐字保留单位）
- `baseline/drift.csv` —— 天平漂移校正
- `baseline/program.csv` —— 炉程序（ramp / isothermal）
- `baseline/gas.csv` —— 气体阀事件（阀时间 ≠ 样品反应时间）
- `baseline/blank.csv` —— 空白曲线
- `baseline/init_mass.csv` —— 样品初重分层

## 反例与边界（只改一个直接来源）
- `revision/samples_v2_gap.csv` —— 采样缺口（8.0→10.5 min 缺测；禁止跨缺口插值）
- `revision/drift_v2.csv` —— 天平基线漂移增强（局部依赖）
- `revision/gas_v2.csv` —— 气氛延迟：阀切换提前，反应窗仍滞后到达
- `revision/gas_bad.csv` —— 导入半失败（非法 action；本层失败，其余层不受影响）
- `revision/samples_bad_header.csv` —— 明确格式错误（表头不符）
- `revision/samples_bad_rows.csv` —— 行级部分失败（坏行成诊断，好行提交）
- `revision/init_mass_v2.csv` —— 初重修订（只让依赖初重的下游过期）

## 叙事脚本（与 UI 一致，不是彼此无关的按钮）
1. 建立项目，按六层导入基线 → 运行推导产生候选。
2. 参数修订：把气氛延迟 1.5→2.5 min、热滞后 4→6 K（一次参数修订）。
3. 只改一个直接来源：导入 `drift_v2.csv`（局部依赖过期）。
4. 人工冲突：对同一阶段先 accept 后 reject，系统记录冲突，再显式裁决并可撤销。
5. 进入第二个分支：导入 `samples_v2_gap.csv` 与 `gas_v2.csv`，验证反应窗、
   重叠阶段、缺口不插值。
6. 导入 `gas_bad.csv` 触发半失败；确认好层仍在、坏层留下诊断。
7. 最终复核：四视图同步（TG/DTG、炉程序、气氛时间线、阶段候选），展开残留率
   计算链，回溯到源行、算法版本、参数指纹与人工决定。
8. 导出 → 删除本地数据库 → 导入；身份、顺序、来源关系保持不变。

## 机器可读的判断依据
- `assertions.json` —— 每条领域判断（阀时间≠反应时间、阶段可重叠、不强制 100%、
  缺口不插值、未知残留是一等状态）及对应事件类型与可验证谓词。
